# Asset provenance

`ashtray.png` was generated for Flicky Ashtray with OpenAI's built-in ImageGen route on 2026-07-14. It is a new, original deep blue-gray, rounded ashtray asset based only on the supplied product-form references. `ashtray-chroma.png` is its magenta chroma-key source; `ashtray.png` is the locally removed-background PNG used by the app.

`cigarette.png`, `cigarette-butt.png`, `ash-sprinkle.png`, and `ash-full.png` were generated as one style-matched ImageGen atlas on the same date, split into independent cutouts, chroma-keyed locally, alpha-validated, and trimmed for native UI placement.

`ash-over.png` and `ash-filthy.png` are two later built-in ImageGen sprites for the limit-reached and severely-over-limit states. They use the existing ashtray and butt pile as style/perspective references, were generated on a flat magenta chroma background, then locally keyed, alpha-validated, trimmed, and reduced to a 512 px maximum edge.
